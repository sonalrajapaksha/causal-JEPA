# Experiment 2: Model B representation collapse

The nine matched runs use the existing 2,400/300/300 train/validation/test splits, first four frames, 32-dimensional eight-slot Model B, AdamW 0.0003, batch 8, five epochs, EMA 0.99, seeds 42/43/44 and the final epoch checkpoint. No model choice or hyperparameters use test outcomes. B1 has the exact original controlled experiment objective (prediction MSE + 10 times raw variance floor 0.1 + 100 times raw covariance penalty). B2 replaces the latter penalties with a variance floor of 0.5 weighted 10 and off-diagonal covariance squared weighted 1, both applied to pooled embeddings after parameter-free per-vector layer normalization. The prediction loss remains in the original latent space. These coefficients were fixed before the test evaluation; there is no claim they are optimal. B3 uses the B1 objective and a linear head with an additional unit-weight MSE on standardized ball position and velocity. This is a supervised reference, not self-supervised JEPA. Its four-output head adds 132 trainable parameters; the backbone is unchanged. Ball state scaling uses training data only. B1 and B2 have the same parameter count.

The slot encoder is framewise: each frame is encoded independently and no temporal context enters the frozen frame probe. The JEPA predicts each next-frame slot from current-frame slots, by index. Slot indices are learned queries, not validated object identifiers. The supervised head and probes use pooled slots; labels refer to the ball globally, not a designated slot. Validation-only Hungarian matching compares same-index and minimum-cost temporal latent assignments; it cannot validate actual object identity. Train-fitted ridge probes report held-out next-frame state by transition subset as well as all-frame metrics. Interventions label the transition into the probed next frame. Baselines fit only on the training split; two-frame pixels use current frame and difference from the previous frame, while the position-difference oracle has simulator coordinates. State transition baselines use current simulator state and are supervised oracles.

Each model's prediction MSE must be compared only with persistence in its own target latent space. Effective rank measures distribution of embedding covariance, not physical understanding. Per-seed scatter is descriptive, not a confidence interval. Same-index target matching is an architectural assumption; matching cost cannot prove object identity. Interventions are observational subsets and may co-occur.

Run with `scripts/collapse_experiment.py train --variant b1 --seed 42` (repeat variants and seeds), then `baseline`, `evaluate`, `scripts/audit_collapse_slots.py`, and `scripts/plot_collapse_experiment.py`. Existing results are untouched.
